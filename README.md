# irontable

进程内存中的事务执行库（MVCC 快照隔离 + 行级写锁），由上层直接调用，无持久化。

## 用法

```go
db := irontable.NewDB()
db.Seed(map[string]any{"row-1": 100}) // 初始数据由调用方提供

tx := db.Begin()
v, ok, err := tx.Get("row-1") // 读自己的写集，否则读事务开始时的已提交快照
err = tx.Put("row-1", 200)    // 覆盖已有行；必要时等待行锁，最长 5 秒
err = tx.Commit()             // 多行更新整体提交；或 tx.Rollback() 整体撤销
```

## 语义

- 每个事务读取其开始时的已提交视图，叠加自身更新；读从不阻塞。
- 提交前更新对其他事务不可见；提交作为整体进入后续新事务的视图。
- 行被事务占用期间，竞争者等待最长 5 秒；持有者回滚且无冲突时等待者继续。
- 目标行在本事务开始后被他人提交过（即使改回原值），整笔事务失败回滚。
- 等待超时撤销整笔事务并释放全部行锁；已结束事务拒绝一切操作。
- 其他线程可调用 `Rollback` 主动撤销等待中的事务，等待调用随即失败返回。
